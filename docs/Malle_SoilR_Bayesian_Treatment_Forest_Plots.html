title: “Malle ERW: Bayesian SoilR Treatment Comparisons” subtitle: “Primary treatment-versus-Control forest plots” format: html: toc: false number-sections: false embed-resources: true code-fold: false self-contained: true execute: echo: false warning: false message: false error: false freeze: autoOverviewBayesian comparisons of soil carbon decomposition rates, transfer coefficients, and carbon persistence metrics were conducted using posterior distributions obtained from previously fitted three-pool SoilR models for each treatment (Control, Lime, Bolsdorfer, Hühnerberg, and Eifelgold). Posterior parameter samples were extracted from the existing Markov chain Monte Carlo (MCMC) outputs after excluding the first 20,000 iterations as burn-in, with 1,000 posterior draws retained per treatment. The parameters evaluated included the decomposition rates of the fast, intermediate, and slow carbon pools (\(k_f\), \(k_i\), and \(k_s\), respectively), and the transfer coefficients between the fast and intermediate pools (\(\alpha_{fi}\)) and intermediate and slow pools (\(\alpha_{is}\)). For each posterior parameter draw, carbon pool ages and whole-system transit time were derived using the SoilR functions systemAge() and transitTime(), respectively, with a mean carbon input of 100 and an age grid ranging from 0 to 500 years. This provided posterior distributions for the mean ages of the fast particulate organic matter (fPOM), occluded particulate organic matter (oPOM), and mineral-associated organic matter (MAOM) pools, as well as the overall system transit time.Treatment effects were evaluated through posterior contrasts between each amendment treatment and the Control, comprising Lime, Hühnerberg (50 t ha\(^{-1}\)), Eifelgold (50 t ha\(^{-1}\)), and Bolsdorfer (50 t ha\(^{-1}\)). For each contrast, 10,000 differences were generated by independently sampling from the corresponding treatment and Control posterior distributions. The median posterior difference and associated 95% credible interval (CrI; 2.5th and 97.5th percentiles) were calculated, together with the posterior probabilities that the treatment value was greater or lower than the Control value. A treatment effect was considered to be supported by the posterior distribution when its 95% CrI did not include zero. Results are presented as forest plots of treatment–Control differences. All comparisons were based on the existing treatment-level SoilR model outputs; consequently, these contrasts quantify differences between treatment-level posterior distributions and do not represent a hierarchical model of plot-level variation.Load saved Bayesian resultsThis document loads the completed RDS object generated by Malle_SoilR_Bayesian_Treatment_Comparisons.R. make_primary_forest_plot <- function( group_name, responses, x_axis_label ) {

plot_data <- primary_contrasts %>% filter(Response %in% responses) %>% mutate( Response_label = factor( response_label(Response), levels = response_label(responses) ), Comparison = paste(Treatment, “minus Control”), Comparison = factor( Comparison, levels = rev(c( “Lime minus Control”, “HB 50 minus Control”, “EG 50 minus Control”, “BD 50 minus Control” )) ) ) %>% arrange(Response_label, Comparison)

if (nrow(plot_data) == 0) { return(NULL) }

ggplot( plot_data, aes( y = Comparison, x = Difference_median ) ) +

# Zero reference line.
geom_vline(
  xintercept = 0,
  linewidth = 0.5,
  linetype = "dashed",
  colour = "grey45"
) +

# 95% credible intervals.
geom_errorbar(
  aes(
    xmin = Lower_95,
    xmax = Upper_95
  ),
  orientation = "y",
  width = 0.18,
  linewidth = 0.6,
  colour = "black"
) +

# Posterior median differences.
geom_point(
  size = 2.2,
  colour = "black"
) +

# Facet layout aligned with general Bayesian plotting script.
facet_wrap(
  vars(Response_label),
  ncol = 1,
  scales = "free_x"
) +

labs(
  title = paste(
    "Primary Treatment Contrasts:",
    unname(group_titles[group_name])
  ),
  subtitle = paste(
    "Posterior treatment-minus-Control differences;",
    "points show posterior medians and lines show 95% credible intervals"
  ),
  x = x_axis_label,
  y = NULL
) +

theme_bw(base_size = 11) +

theme(
  plot.title = element_text(
    face = "bold",
    size = 13
  ),
  plot.subtitle = element_text(
    size = 9,
    colour = "black"
  ),
  strip.background = element_rect(
    fill = "grey92",
    colour = "grey40"
  ),
  strip.text = element_text(
    face = "bold",
    size = 9,
    hjust = 0
  ),
  panel.grid.minor = element_blank(),
  axis.text.y = element_text(
    size = 8,
    colour = "black"
  ),
  axis.text.x = element_text(
    size = 9,
    colour = "black"
  ),
  axis.title.x = element_text(
    margin = margin(t = 8)
  ),
  panel.spacing = unit(
    1,
    "lines"
  ),
  plot.margin = margin(
    8, 12, 8, 8
  )
)

} Decomposition rates#| label: forest-decomposition #| fig-width: 8 #| fig-height: 7
